# Agent 发放设备配置

在用户要求凭据独立管理、配置更新、换机或凭据统计时读取。操作入口见项目 `docs/devices.md`。

## 发放

Agent 通过已验证 SSH 安装 `ops/install_devices.py` 的管理工具，使用 `ops/register_device.py` 为每个凭据名称生成或复用 UUID。私有注册表位于 VPS，目录 700、文件 600；输出原生客户端文件，Clash Verge 可操作时直接导入，手机使用私有文件或本机生成的二维码。不要将凭据贴入聊天或上传第三方转换服务。

同名活动设备重试或更新必须复用凭据。多个设备可以共用同一凭据，跨客户端格式导出保持 UUID 不变；需要独立计费或撤销时使用不同名称；不能隐式轮换正在使用的配置。配置更新由 Agent 执行并重新导入，不宣称客户端会自动刷新。默认不安装订阅 HTTP 服务、隧道或申请订阅域名。

## 安全边界

允许用户主动共用配置，不绑定硬件、IP 或客户端型号。认证、在线状态与用量以凭据为单位；同一凭据的多个客户端视为同一身份。安全重点是服务端不公开下载配置，注册表、文件、日志、备份、监控与代码仓库不泄露凭据。

## 迁移、撤销与统计

生成配置后通过实际内核语法校验；切换客户端，再验证两个出口站、国内直连和实际激活配置。所有旧客户端验收前保留共享旧凭据。手机不可操作时明确保留待验收状态。

撤销要从 Xray 移除该用户；删除本地配置文件不能让已分发的凭据失效。候选配置语法测试后事务式应用，失败恢复内容、属主和权限；管理变更串行执行，避免并发覆盖其他设备。

在线数按 Xray 凭据身份去重，共享旧凭据也只计一次，不推断物理设备数。节点 TCP 总连接数单列，不能冒充某凭据的精确会话数。StatsService 仅回环且仅 root 可访问；`python3 -m devices.usage` 私下查询凭据在线和当前 Xray 进程周期上下行流量，重启后计数重置。公开监控只发汇总，不发凭据标签、来源 IP、UUID 或逐凭据明细。

## 验收

检查不同设备凭据不同、同设备重试保持不变、并发发放不丢失其他用户、撤销使节点认证失效、失败恢复原配置，以及私有文件权限和公开状态脱敏。模拟测试不能替代客户端实机验证。
