# 安全基线与闲置软件清理

在部署、维护或用户明确要求安全收尾时读取。依据目标机器的实际依赖行动，不把某台机器的清理清单当作所有主机的卸载指令。

## SSH 与 fail2ban

- 密钥登录；禁止密码、交互式密码和 root SSH 登录。检查 sshd -T 的有效值以及 cloud-init/drop-in 的优先级。
- 管理端口可配置，默认建议 22222；更改端口减少常规扫描，不能代替密钥认证或防火墙。
- 迁移前备份 SSH、UFW、fail2ban 配置，并建立定时回滚。先双端口监听和放行，再由独立新会话完成密钥认证及 sudo 验证；然后去掉旧端口监听与 IPv4/IPv6 放行，复测后取消定时回滚。
- 同步本机 SSH 别名、HostKeyAlias、known_hosts 及实际依赖端口的工具。信任已有验证指纹，不关闭主机密钥校验。
- 从系统软件源安装 fail2ban；使用 systemd 日志后端，sshd jail 保护实际管理端口。可采用 10 分钟内 5 次失败封禁 1 小时，依据误报情况调整。
- 核验 jail active、日志匹配、开机启动及双栈封禁链。不对当前管理地址执行封禁测试；如用文档地址测试封禁动作，应立即解封。
- 系统更新先查看计划，保持恢复路径；更新后复测 SSH、代理服务、两站固定出口，明确是否需要重启。

## 最小化组件与暴露面

列出服务、监听、自启动、客户端当前配置、连接/握手/流量和依赖关系。只有确认不再使用时才清理历史协议、旧 HTTP/SOCKS 服务、备用监听和临时诊断组件。

按事务执行：备份配置与包版本 → 停服务和自启动 → 移除已确认闲置的软件包 → 移除对应监听、双栈防火墙规则、NAT、转发、sysctl → 清理客户端旧启动项 → 主链路回归验收。

不执行泛化的 apt autoremove/purge、不 flush 防火墙、不禁用未知系统组件。云初始化、系统更新、DNS、时间同步及厂商管理依赖不能仅因“当前没有连接”就删除。备份加密/限制权限，保留恢复所需信息，不把旧凭据或导入链接放进项目。

TCP VLESS 入口承载 UDP 流量不意味着需要额外开放同端口 UDP。仅保留实际服务所需端口，关闭用不到的备用入口。监控不能为了图省事新开公网 SSH/HTTP 代理或管理面板。

## 监控权限

route-pilot 的生产采集由 VPS systemd timer 驱动：root 只读采样，独立无登录账户通过 HTTPS 上报。上报凭据由 systemd LoadCredential 加载，不进入命令行或日志。Cloudflare 独立探测入口；不要求 Mac 保持运行。若另外启用旧版 SSH 诊断，使用 restrict + 固定只读命令与最小 sudo 权限。禁止把管理用户的全权限私钥复制到 WebUI 或采集服务。

控制台默认仅监听本机回环；运行状态、凭据、数据库在项目之外，目录 700、私密文件 600。网页只提供只读查询，过滤凭据、命令输出和无关用户连接详情。

## 验收证据

记录本次改动来源、有效端口、jail 状态、系统包变更、回滚路径及实际出口。已经由其他会话完成的工作以只读核验接收，不重新安装、不重复覆盖配置。手机未重测时明确标记，不能用 Mac 的成功替代手机验收。

## 设备凭据

按 [设备发放与迁移](devices.md) 执行。管理 SSH、采集令牌和各设备的节点 UUID 分开保存，不能混用。Agent 通过 SSH 管理私有注册表，无公网注册或配置下载接口。独立凭据不等于不可复制的硬件认证；完整配置被复制后仍可能用于其他设备。只公开汇总计数，设备名、地址和配置均不进入状态页。

## Xray 进程与凭据隔离

在已有静态非 root 账户的 Xray 服务上，先安装项目管理工具，再运行 `ops/harden_runtime.py`。它只管理本项目的 drop-in 和 nftables 表，备份候选配置、验证语法、失败回滚，不重置 UFW 或修改 SSH。DynamicUser 不能猜 UID，需先选择明确的网络隔离方案。

- 持久配置 root:root 600，通过 systemd LoadCredential 交给运行进程；注册表、管理设置和备份保持 root 私有。
- 删除不必要的 NET_ADMIN/NET_RAW，只留绑定低端口所需能力；只读系统目录，保护家目录、内核与控制组，隔离临时目录与设备。
- 限制 core dump 并清空转储内存过滤项，访问日志关闭、错误日志 warning；检查 journal 是否意外包含 UUID、私钥或采集令牌，扫描只报告命中数。
- 应用路由与主机 UID 出口过滤同时阻止代理访问回环、内网、链路本地和云元数据；保留 DNS 与公网访问。StatsService 回环端口仅允许 root 本地查询。
- 负向实测：采集账户和普通账户不能读节点凭据、不能访问 StatsService；Xray UID 不能连接元数据/内网；root 统计查询与两个公网固定出口测试须通过。
- 私有文件拒绝符号链接、硬链接和非预期属主；原子写入，不能因调试把凭据加到日志、命令行、测试夹具或公开报告。

允许按凭据主动共享配置，不强制每物理设备一份。服务进程需要使用活动凭据，不能承诺该进程或 root 被攻破后仍绝不泄漏；验收应报告已检查的边界与剩余信任前提。
